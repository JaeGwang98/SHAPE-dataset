# SHAPE dataset

Synthetic Korean patient questions labelled with 26 inflammatory diseases, released with the paper
**"SHAPE: Symptom-based Hypothetical-driven Augmented Prompt Engineering"** (Shin J, et al.; under review at *Scientific Reports*).

All questions were generated by large language models from a public disease–symptom dataset.
**No real patient records were used**, and the data contain no personal information.

> ⚠️ These are synthetic data for research on text classification and data generation.
> They are not clinically validated and must not be used for diagnosis or medical advice.

## Files

| File | Rows | Columns | Role in the paper |
|---|---|---|---|
| `data/train.csv` | 145,600 | `질문`, `labels` | Training set (Table 4, ablations, baselines) |
| `data/validation.csv` | 15,600 | `질문`, `labels` | Internal validation set, used only to monitor training |
| `data/test_100.csv` | 100 | `질문`, `질병명_리스트` | 100-question test set used for all reported accuracies |
| `data/test_100_revised15_originals.csv` | 15 | `test_id`, `original_question`, `revised_question` | Wording of the 15 test questions before and after the physician's revision (`test_id` = row number in `test_100.csv`) |
| `ratings/rs_only_390_ratings.csv` | 390 | `id`, `disease`, `rating_A/B/C` | Physician quality ratings (1–4) of 390 RS-only questions by raters A, B, C (Table 3, rater statistics) |
| `ratings/ri_130_ratings.csv` | 130 | `id`, `disease`, `source`, `row`, `variant`, `original_symptoms`, `inserted_symptom`, then per rater A, B, C: `realism_1to4`, `label_appropriate`, `plausibility_1to4`, `alt_label` | Physician review of 130 RI questions (one inserted unrelated symptom each) |
| `prompts/fewshot_pool.csv` | 100 | `result` | Few-shot example pool (100 patient questions generated in advance with GPT-4o; 3 are drawn at random per prompt; the same pool was used for all generation requests) |
| `code/` | – | – | Generation, preprocessing and analysis scripts (`code/analysis/` = training/ablation/statistics scripts; see below) |

- `질문` — the generated patient question (Korean).
- `labels` — the disease label (Korean name, one of the 26 diseases below).
- `질병명_리스트` — one to three physician-accepted labels, comma-separated (split on `,` and strip whitespace).
  The first-listed label is the disease used for generation (primary label).
  A prediction is counted as correct if it matches any accepted label (any-match accuracy).

All files are UTF-8 with BOM (`encoding="utf-8-sig"` in pandas).

### How the sets were built

- **train.csv / validation.csv.** GPT-4o-mini (`gpt-4o-mini-2024-07-18`) and GPT-4.1-mini (`gpt-4.1-mini-2025-04-14`)
  generated 156,000 questions from symptom lists of the Kaggle Disease–Symptom Dataset, after random swap (RS) and
  random insertion (RI) of symptoms. 145,600 of these form the training set. The validation set contains the remaining
  10,400 RS-only questions plus 5,200 GPT-4o (`gpt-4o-2024-08-06`) responses to the same RS-only prompts (600 per disease).
- **test_100.csv.** Generated separately: GPT-4o received only a randomly drawn disease name and wrote one patient question
  without naming the disease. A family medicine physician assigned one to three accepted labels; the wording of 15 questions
  was revised during labelling, and this file contains the revised wording. 36 questions have one label, 42 have two and 22 have three.
  Periodontitis does not appear in the test set.

Per-disease counts in `train.csv` are 5,600, except stomatitis (3,680) and gastroenteritis (7,520):
during generation, 960 prompts intended for stomatitis were generated from gastroenteritis source rows.
Those prompts are label-consistent with their source rows (see the paper's Methods).

## Source data

Symptom lists were derived from the Disease–Symptom Dataset on Kaggle
(<https://www.kaggle.com/datasets/dhivyeshrk/diseases-and-symptoms-dataset>, World Bank Dataset Terms of Use).
The source dataset is not redistributed here. The selection of the 26 diseases was based on outpatient disease frequency
statistics of the Health Insurance Review & Assessment Service (HIRA) of Korea, 2022–2024.

## Ratings, prompts and code

- **Raters.** Raters are identified only as A, B and C. The same three raters rated both the 390 RS-only questions and the 130 RI questions.
  No names or affiliations are included. Rating scale and criteria are described in the paper's Methods.
  `label_appropriate` is 예/아니오 (yes/no); `alt_label` is the rater's suggested disease when the answer is 아니오. (For rater B, item 120, the answer cell contained the alternative label 질염 instead of 예/아니오; it is recorded here as 아니오 with `alt_label_B` = 질염, as disclosed in the paper's supplement.)
- **Prompts.** The Korean system prompts are in the generation scripts: `code/Data_gen.py` (symptom-based generation, zero-shot),
  `code/Data_gen_prompt.py` (few-shot batch requests; examples drawn from `prompts/fewshot_pool.csv`) and `code/few_shot_data_gen.py`
  (generation of the few-shot pool and of the test set).
- **Code.** Scripts were run in the author's local environment and still contain local relative paths (e.g. `../2025_05_19_data/…`);
  adjust the paths to the files in `data/` to rerun. File names of the rating workbooks were anonymised in the scripts
  (`raterA`, `raterC`), so the rating-statistics scripts (`r01`, `r05`, `r08`) need the original workbooks renamed accordingly
  or the CSVs in `ratings/` as input. The OpenAI API key is read from the `OPENAI_API_KEY` environment variable; no key is stored in this repository.
